MERN Coupon Generator App

A full-stack MERN application that allows authenticated users to create and manage discount coupons. Users can upload coupon images, generate unique QR codes 
and coupon links, and edit or delete coupons anytime. Designed for small businesses, e-commerce platforms, and promotional campaigns.

Features

 User registration & login (JWT Authentication)
 Create coupons with discount details
 Upload coupon image/photo
 Generate unique QR code for each coupon
 Generate shareable coupon link
 Edit coupon details
 Delete coupons
 Redeem / validate coupons
 Secure Express API
 MongoDB persistence
 Responsive UI

 Tech Stack
Layer	                   Technology
Frontend            	React, Tailwind / CSS
Backend	              Node.js, Express.js
Database	            MongoDB / Mongoose
QR Code	              qrcode npm package
Auth	                JWT, bcrypt

2️ Install dependencies
Backend

Frontend
